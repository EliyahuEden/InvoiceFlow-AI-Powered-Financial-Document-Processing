## Set up on a new computer
1. Install Git and Docker Desktop. For local development also Python 3.12+ and Node 22.
2. `cp .env.example .env`, add a Groq key (`OPENAI_API_KEY`) if you want live AI, then:
   ```
   docker compose up -d --build
   docker compose exec api python -m app.cli seed --reset
   ```
3. Open http://localhost:3000, log in as `finance@kinneret.example` / `InvoiceFlow!2026` (demo only).
4. Ports: web 3000, API 8010, Postgres 5433, Redis 6380, S3 8333, Mailpit inbox 8025.
5. On Windows with Git Bash, prefix `docker compose run … -v ./x:/srv/x …` with `MSYS_NO_PATHCONV=1`.
6. After pulling a new migration: `docker compose exec api python -m app.cli migrate` (the API also migrates on start).

## Known gotchas
- **OpenAI SDK and `OPENAI_BASE_URL`:** with `base_url=None` the SDK reads the `OPENAI_BASE_URL` environment variable
  (Groq's address in Docker), which once sent the OpenAI key to Groq. Every provider passes an explicit address
  (`OFFICIAL_OPENAI_URL`); `tests/test_llm_fallback.py` guards it.
- **401 means "signed out" to the frontend:** `lib/api.ts` answers any 401 by refreshing the session and sending the
  user to the login page. A wrong password or code inside a signed-in form must return 403 (or 422), never 401.
- **Migrations:** new columns on `users` need no RLS (users are not tenant data); tenant tables need RLS policies
  like the existing ones. Memberships across businesses are read with `new_session()` (no org), as at sign-in.
- **Audit records** are per business: call `set_session_org(s, org_id)` before `audit.record` in a session opened
  without an org.
- Regenerate demo PDFs inside Docker (`docker compose run … python -m app.cli generate-docs`) so fonts match the
  committed files; restore unchanged ones with `git checkout`.
- OCR (Tesseract) exists only in the Docker image; locally, scanned invoices fail with a clear message.
- Next.js's `/api` proxy forwards a client's `X-Forwarded-For` unchanged: in production only Caddy may be exposed.
- The browser's "network idle" never comes on signed-in pages (live-update connection); wait for content instead.
  In browser tests, fill fields with the `fill()` helper in `accounts.spec.ts` (typing before hydration is lost).
- On Windows, shell heredocs mangle Hebrew and quotes in patch scripts: write patch scripts to a file first.
